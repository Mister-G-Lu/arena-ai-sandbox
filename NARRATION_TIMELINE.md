### State Management:

Add to GameStateContext:
```javascript
// Track which narrations have been shown
narrations: {
  firstTask: false,
  firstAnomaly: false,
  firstDeath: false,
  arc1to2: false,
  promotion1: false,
  // ... etc
}

// Function to show narration
showNarration: (narrationId) => {
  if (!state.narrations[narrationId]) {
    setState(prev => ({
      ...prev,
      narrations: { ...prev.narrations, [narrationId]: true }
    }));
  }
}
```
